All three shots below are in the repo and wired into the README; they were captured from `./out/demo`
(the demo pages, generated by the two commands in the README) at 880 px viewport width and 2× scale.
They are not of the unpublished worked example, which is not in this repo.

Suggested capture: viewport width 880 px, device scale 2 (so the PNG is 1760 px wide), light-on-dark as
the pages already are, no browser chrome, full page height.
