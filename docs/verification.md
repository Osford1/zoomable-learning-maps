## 1. Master emitter

`scripts/emit_master.py` was edited in this repo before this run: the hard-coded absolute path to the
author's own skill folder was replaced with the script's own directory, so `zoom_subchart.py` is imported
from beside it. That is a behaviour change, not a comment change, so the emitter was re-run and the
output below is from the edited file.

```
$ python scripts/emit_master.py examples/spec-master-demo.json --out-dir ./out/demo
demo-structure-flowchart.html                                9886 bytes  canvas 880 x 560

no text-overflow warnings
```

Exit code 0. The `{H}` placeholder in the demo master's footer was substituted with the computed height:
the emitted file's footer reads `canvas 880 × 560 · generated by scripts/emit_master.py; do not
hand-edit the output, edit this spec`.

`python scripts/emit_master.py --help` prints its usage (`usage: emit_master.py [-h] --out-dir OUT_DIR
spec`) rather than an import error, which is what the path fix above was checked against: `emit_master`
imports `zoom_subchart` from its own directory, so the two scripts only work as a pair in the same
folder.

## 4. Rendered-pixel audit

`scripts/audit_headless.py` wraps `scripts/pixel_audit.js` in headless Chrome and measures the rendered
`getBBox()` of every `<text>` after `document.fonts.ready`.

```
$ python scripts/audit_headless.py ./out/demo
OK   demo-structure-flowchart.html                        canvas=0 0 880 560      texts=18   links=2   chips=2   tight=0
OK   demo-z1-the-workflow-zoom.html                       canvas=0 0 880 900      texts=28   links=3   chips=0   tight=0
OK   demo-z2-still-to-build-zoom.html                     canvas=0 0 880 528      texts=14   links=3   chips=0   tight=0

PAGES_BAD: 0
```

Exit code 0: 3 of 3 pages pass, 0 off-canvas, 0 past the 840 px content edge, 0 text collisions.

On the tightest right margin of `0`: it is the content edge, not a violation. Three text elements are
right-aligned to `x="840"` by design — the master's standalone legend note, and on the chart page the
`re-enters the master chart at §1` header note and its legend note — so the measured right edge lands
exactly on 840. The audit reports the margin, and the pass condition is that nothing exceeds it.

## 6. Reproducing

From the repo root, in one shell:

```bash
python scripts/emit_master.py   examples/spec-master-demo.json --out-dir ./out/demo
python scripts/zoom_subchart.py examples/spec-demo.json        --out-dir ./out/demo
python scripts/verify_links.py ./out/demo
python scripts/audit_headless.py ./out/demo
```

`./out/` is in `.gitignore` and is not published; it is created by the first two commands. The audit
needs Chrome or Edge on a standard install path. On Windows the interpreter is `python`, and the gate's
file arguments need native `C:/...` paths rather than MSYS `/c/...` ones.
